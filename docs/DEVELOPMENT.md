# Bot开发队列

1. **HU节点质量**：在原公开历史、价格、深度与条件范围下验证行动价值，记录已知下行；不以合法性测试替代强度。
2. **整体评估**：独立种子/对手/资源条件的离线对照，区分局部行为、整体收益与不确定性。
3. **六人独立策略**：背景桌型、位置、多路范围和记忆分别建模；六人剩两人不自动沿用原生HU结论。
4. **产品集成**：新策略版本/指纹与可见行为验证后更新产品组件锁；保持观察隔离、迟到和合法回退。
5. **平台方向**：旧Chipzen设计仅作输入，SDK/赛制/deadline另核，再连通、记录和离线导入；凭据、参赛和上传独立处理。

旧Python/Next产品的事件/范围/日志反例可按需采用，教师解释属于总产品。原始实验、负结果和旧工具保留在[历史入口](archive/README.md)与[reports](../reports/README.md)。本轮文档整理不启动上述策略工作。
